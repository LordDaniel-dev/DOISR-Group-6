# DOISR-FAIR-Open-Data

Group project for the course signature **DOISR** (Digital Open Infrastructure for Semantic Representation).

## Project Overview

This repository contains a comprehensive implementation of FAIR (Findable, Accessible, Interoperable, Reusable) data principles applied to open data management. The project focuses on developing semantic ontologies and data structures for improved data governance and interoperability.

## Key Components

### Ontology
The project includes a well-defined ontology available in multiple semantic formats:
- **JSON** - For web applications and APIs
- **RDF/XML** - Standard semantic web format
- **Turtle (TTL)** - Human-readable RDF format
- **N-Triples (NT)** - Line-based RDF format
- **SHACL Shapes** - Data validation specifications

### Documentation
- Interactive HTML documentation in English and default language
- Conceptualization diagrams (Draw.io format)
- Use case specifications
- Design decision documentation

### Datasets
Organized datasets in core and additional categories for testing and demonstration purposes.

## FAIR Principles Implementation

This project demonstrates the application of FAIR data principles:
- **Findable**: Organized metadata and semantic structures
- **Accessible**: Open access repository with multiple format exports
- **Interoperable**: Standardized ontology formats (RDF, JSON-LD)
- **Reusable**: Clear documentation and use cases

## Getting Started

1. Review the ontology files in the `docs/` directory
2. Examine use cases in `documentation/Use_cases`
3. Explore the interactive documentation via `docs/index.html`
4. Access datasets in the `datasets/` directory for reference implementations

## File Formats

- **Turtle (.ttl)**: Recommended for human readability
- **RDF/XML (.rdf)**: Standard semantic web interchange format
- **JSON (.json)**: For programmatic access
- **N-Triples (.nt)**: For triple store imports
- **Draw.io (.drawio)**: For architecture visualization
